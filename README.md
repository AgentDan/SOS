# deskOS

Конфигуратор рабочего места. Анкета, каталог и 3D-сцена — инструменты продажи: провести сделку и вернуть клиента.

## Запуск

```bash
npm install
npm test
npm run dev
```

Клиент: http://localhost:5173/  
Сервер: http://localhost:3000
