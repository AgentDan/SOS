# AI

Словарь, разбор фразы и проверка реплики. Обращаться сюда могут только блоки понимания и голоса.

Подключено: `llm.js`. Его вызывает разбор фразы (`understanding/parse-with-llm.js`), когда словарь вернул `unclear` с причиной `no_match`. Модель только предлагает intent, решает код. Выключенный AI, сбой, таймаут или негодный ответ оставляют словарный результат.

Не подключено: голос. Реплика через AI и отбраковка реплик отсюда не вызываются.
