# Коллайдеры

Коробка части хранится в самом GLB: пустой узел `COL_<часть>`, без mesh и без поворота. `translation` — центр в координатах модели, `scale` — полный размер по осям (узел изображает куб 1×1×1 с центром в своём начале). `extras.collider` равен `"box"`.

`addCollidersToGlb(buffer, { type })` читает GLB, выбрасывает прежние `COL_*` вместе с потомками и записывает новые. BIN-чанк не меняется. Возвращает `{ glb, parts, sizeMm, bounds }`. `parts` — `{ name, center, size }` в метрах, в координатах модели, без переноса в центр габарита. Любая проблема — `ColliderError`, файл вызывающий код не сохраняет.

Стратегия зависит от `type`.

`chair` по-прежнему собирает Seat, Back и Base и необязательный Armrest по именам узлов. Колёса и ролики не входят. Если нужной роли нет, ошибка прежняя: расчёт по форме для кресла не включается.

`desk_legs` сначала берёт узлы `Leg_`, `Foot_`, `Frame_`, `Post_`, `Plate_` и пропускает мелочь меньше 10 мм. Если такая часть не нашлась, либо нашлась ровно одна и коэффициент заполнения ниже `FILL_THRESHOLD` (0.6), коробки считаются по форме.

Остальные типы, включая `desk_top` и `monitor`, группируют узлы по имени. Если группа одна и коэффициент заполнения ниже `FILL_THRESHOLD` (0.6), эта коробка заменяется расчётом по форме. Сплошная столешница или монитор дают коэффициент около 1 и остаются одной коробкой по имени узла.

Расчёт по форме делит габарит на ячейки `max(0.01 м, длиннейшая сторона / 64)`. Ячеек не больше 262144, ячейка не меньше 0.01 м. Треугольники всех мешей, кроме узлов `COL_*`, помечают ячейки поверхности; заливка с границы сетки отделяет пустоту, остальное считается твёрдым. Если у примитива нет индексов и число вершин не делится на три, а сами вершины сидят только в углах своего габарита, это сплошная коробка: так задан ящик из восьми углов, а не сетка. Из твёрдых ячеек жадно собирается до 12 коробок, по убыванию объёма. Если после 12 коробок занятыми остаются больше 5 % твёрдых ячеек, новые коробки не добавляются. Имена этих коробок — `Auto_1`, `Auto_2`, …. Коэффициент заполнения — доля твёрдых ячеек в габаритной коробке части, на той же сетке.

Нужна хотя бы одна часть и не больше 12. Если по форме не осталось ни одной коробки, это ошибка. Общей коробки на всю модель нет, когда части ищутся по именам и не нашлись: в тексте ошибки есть ожидаемые имена и список узлов файла.

Узлы без mesh и любые `COL_*` во входном файле в расчёт габарита не входят.
