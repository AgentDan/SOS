# Коллайдеры

Коробка части хранится в самом GLB: пустой узел `COL_<часть>`, без mesh и без поворота. `translation` — центр в координатах модели, `scale` — полный размер по осям (узел изображает куб 1×1×1 с центром в своём начале). `extras.collider` равен `"box"`.

`addCollidersToGlb(buffer, { type })` читает GLB, выбрасывает прежние `COL_*` вместе с потомками и записывает новые. BIN-чанк не меняется. Возвращает `{ glb, parts, sizeMm, bounds }`. `parts` — `{ name, center, size }` в метрах, в координатах модели, без переноса в центр габарита. Любая проблема — `ColliderError`, файл вызывающий код не сохраняет.

Стратегия зависит от `type`. `desk_legs` берёт узлы `Leg_`, `Foot_`, `Frame_`, `Post_`, `Plate_` и пропускает мелочь меньше 10 мм. `chair` собирает Seat, Back, Base и необязательный Armrest; колёса и ролики не входят. Остальные типы, включая `desk_top` и `monitor`, группируют узлы по имени. Нужна хотя бы одна часть и не больше 12. Общей коробки на всю модель нет: если части не нашлись, в тексте ошибки есть ожидаемые имена и список узлов файла.

Узлы без mesh и любые `COL_*` во входном файле в расчёт габарита не входят.
