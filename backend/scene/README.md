# Сцена

Миллиметры. Ось x вправо от лица сидящего за столом, y вверх от пола, z к сидящему (вперёд от стола). Начало — центр пола под ножками стола.

Положение предмета: `{ sku, x, y, z, rotY }`. x и z — центр охвата в плане, y — низ предмета над полом, `rotY` в градусах (0 — лицом к +z, к сидящему). Охват — прямоугольный ящик из `dimensions` каталога: width по x, height по y, depth по z. При `rotY` 0 или 180 размеры осей не меняются.

`layout.js` ставит предметы по этим правилам и ничего не пишет в сцену. `distance.js` считает зазор между двумя охватами. Отказ «не влезает» остаётся в командах.

План сцены считается в `scene-plan.js` из товаров `alwaysPresent`, разрешённых потребностей и журнала `sceneEdits`.

Базовый список (опоры и потребности) уникален. Дальше артикул может повторяться: `add` дописывает копию в конец, `remove` снимает одну последнюю копию, `replace` меняет первое вхождение. Сколько копий можно поставить, решает `maxOnScene` типа, если он задан. Влезает ли предмет на опору, проверяют команды.
