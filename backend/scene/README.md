# Сцена

План сцены считается в `scene-plan.js` из товаров `alwaysPresent`, разрешённых потребностей и журнала `sceneEdits`.

Базовый список (опоры и потребности) уникален. Дальше артикул может повторяться: `add` дописывает копию в конец, `remove` снимает одну последнюю копию, `replace` меняет первое вхождение. Сколько копий можно поставить, решают `maxOnScene` типа и `limits.maxItems` сцены.
