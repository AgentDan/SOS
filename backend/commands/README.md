# Команды

Исполнитель команд клиента (добавить, убрать, заменить). Сцену меняет только через переданную функцию `scene.apply`; `scene` и другие блоки не импортирует.

К AI не обращается. Текст реплик не пишет: возвращает код и факты для блока «Ответ».

Артикул на сцене может повторяться. Повторный `add` проходит, пока тип не достиг `maxOnScene` (если предел задан) и предмет помещается на опору. Общего предела предметов нет. `replace` на тот же артикул, который и заменяют, отклоняется (`same_sku`).
